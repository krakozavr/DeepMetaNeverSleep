посмотри, если ли способ автоматизировать добавление избранных (liked) брифов из DeepMeta в Google Calendar как задачу (task). Собственно в задачу должны добавиться: 
- название брифа 
- дата дедлайна 
- ссылка на бриф на ESP (в самом низу в описании брифа) 

В идеале задачи должны добавляться по определённым правилам (в определённый аккаунт но creative vs CC - в разные списки) 

Dариант с hfcibhtybtv фугкциональности имеющегося плагина мне видится самым правильным. 

В настройках плагина должен быт выбор аккаунта и списков для добавления, чтобы пользователь мог это настроить. API DeepMeta не планируется ни в каком обозримом времени (с разработчиком мы активно сотрудничаем)

Что есть под капотом
DeepMeta использует внутренний API (не публичный), который можно задействовать для автоматизации:
Endpoint 1 — список лайкнутых брифов:
GET https://deepmeta.creativ.zone/api/dm-briefs
  ?sort=0&descending=true&uiLikes=6&search=
Возвращает: { espId, rating, lastViewedAt, totalCount }, где rating: 100 = лайкнутый бриф. У тебя сейчас 20 лайкнутых брифов.
Endpoint 2 — детали конкретного брифа:
GET https://deepmeta.creativ.zone/api/dm-brief/{uuid}
Возвращает: название, описание, дата дедлайна (например "DEC 31, 2026").
Проблема: API лайков возвращает только espId, а API деталей принимает внутренний uuid. Прямого маппинга нет — UUID можно получить только при клике на карточку через React state.

Как можно автоматизировать
Вариант 1 — Make/Zapier (без кода, рекомендую)

Make (ex-Integromat) → модуль HTTP Request → запрос к /api/dm-briefs?uiLikes=6 с твоими сессионными куками
Фильтр: rating = 100
Второй HTTP-запрос для получения деталей каждого брифа по UUID (UUID нужно перехватить вручную один раз или через браузерный скрипт)
Модуль Google Calendar → Create Task с названием и датой дедлайна

Сложность: API не публичный — нужно передавать авторизационные куки из браузера. Они действуют несколько дней/недель и их нужно периодически обновлять.
Вариант 2 — Google Apps Script (код, бесплатно)
javascriptfunction syncLikedBriefs() {
  const cookies = 'ТВОИ_КУКИ_ИЗ_БРАУЗЕРА'; // скопировать из DevTools
  
  const response = UrlFetchApp.fetch(
    'https://deepmeta.creativ.zone/api/dm-briefs?sort=0&descending=true&uiLikes=6&search=',
    { headers: { 'Cookie': cookies } }
  );
  
  const briefs = JSON.parse(response.getContentText()).filter(b => b.rating === 100);
  const calendar = CalendarApp.getDefaultCalendar();
  
  briefs.forEach(brief => {
    // Создать задачу с дедлайном
    calendar.createEvent(brief.espId, new Date(brief.deadline), new Date(brief.deadline));
  });
}
Этот скрипт можно запускать по расписанию (каждый день).
Вариант 3 — Chrome Extension (самый надёжный)
Расширение само перехватывает авторизацию, работает пока ты в браузере, и может автоматически добавлять в Google Calendar при лайке брифа в реальном времени.

Главное ограничение
DeepMeta не предоставляет публичного API — нет документации, нет API-ключей. Все запросы авторизуются через сессионные куки. Это значит:

Автоматизация технически работает, но хрупкая (куки истекают, структура API может измениться)
DeepMeta потенциально может заблокировать такой доступ
