# Design sources

Not part of the extension package — kept for editing artwork.

- `Icons-set.psd` — source for the toolbar icons in `../icons/`
  (`icon-16-*`, `icon-48-*`, `icon128-*` × `active` / `error` / `waiting`).
- `DeepMetaNeverSleep.png` — promotional image.
- `support_developer.png` — support/donation image.
- `generate_icons_legacy.py` — old Pillow generator for the earlier
  clock-style icons (`icon-<idle|active|error>-<size>.png` naming). It does
  not produce the current icon set; kept for reference only.

Older icon sets (`icons-old/`, `icons-new/`, `icons/icon.svg`,
`icons/generate-icons.html`) were removed in v1.15.4 cleanup and remain in git
history.
